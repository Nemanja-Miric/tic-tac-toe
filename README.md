# Tic-Tac-Toe CLI

Tic-Tac-Toe CLI you can play locally against a friend or a computer. Player 'X' always plays first. The computer will always play a best move (best move being, the first move it finds that is guaranteed to lead to it's best possible result - which can lead to the computer playing a slower, although still a winning move, in certain situations).

# Implemenation

Tic-Tac-Toe CLI implements a basic argument parser, logic for tic-tac-toe, as well as a recursive depth-first search to find a best move. 

# Get Started

To build the project, clone the respository, within the repository folder - run make, and you will be able to start using Tic-Tac-Toe CLI by running ./bin/tic-tac-toe.

# Help

To see all available arguments you can use, run ./bin/tic-tac-toe -h or ./bin/tic-tac-toe --help.
